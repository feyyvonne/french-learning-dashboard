# French A2 Learning Dashboard

A beginner-friendly React and Tailwind dashboard for A2 French study.

## Features

- Vocabulary tracker with saved learning status
- 20 refreshed vocabulary words each day
- Three word states: Unfamiliar, Learning, and Learned
- Present-tense verb conjugation quiz
- Progress, streak, and accuracy stats
- Mobile-friendly layout

## Run Locally

Open `index.html` in a browser. The app uses CDN-hosted React and Tailwind, so an internet connection is needed the first time it loads those libraries.
